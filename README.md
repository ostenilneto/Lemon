# Bem vindo

Com 3 décadas de experiência em tecnologia e desenvolvimento de software de gestão, a equipe de desenvolvimento da Lemon trabalha com seus clientes para entender suas necessidades e criar soluções personalizadas que atendam às suas necessidades exclusivas.

O sistema Kraken é um conjunto de módulos multiusuários integrados para o gerenciamento contábil, fiscal, financeiro, orçamentário, patrimonial, frotas, faturamento, estoque e compras de empresas.
